## Status meanings

- `published`: public backlink is live.
- `ready — browser execution needed`: route and basic eligibility are verified; execute through a supported real browser runtime or connected browser session.
- `blocked — user action`: CAPTCHA or similar manual safeguard requires user interaction.
- `blocked — email verification`: submission requires a real email/verification step.
- `submitted`: a reliable final submission receipt exists.
- `awaiting approval`: the site explicitly confirms moderation/review.
- `submission outcome unknown`: a final action occurred but reliable success evidence is missing; do not retry automatically.
- `hold`: discovery value or backlink outcome is not strong enough yet.
- `excluded`: do not submit under the current campaign rules.

## Backend incident note

The earlier Zearches experiment used GitHub Actions plus custom Python HTML/form parsing. The runner received a page state without the expected form, so the automation failed before a reliable final submission. This campaign now follows the repository-wide browser-first rule: ordinary third-party forms must be executed in a supported browser surface; ad-hoc HTTP form imitation is not a supported backend.
